# 🔑 MetaMask Secret Recovery Phrase Guide

## ⚠️ IMPORTANT SECURITY WARNING

**NEVER share your Secret Recovery Phrase with anyone!**
- Not with me (AI assistant)
- Not with support staff
- Not on any website
- Not in screenshots
- Only enter it in the official MetaMask extension

---

## 🤔 Which Situation Are You In?

### Scenario 1: Creating a NEW Wallet (Recommended for Testing)

If you're setting up MetaMask for the first time for this project:

1. **Click "Create a Wallet"** (not "Import Wallet")
2. **Set a password**
3. **Watch the security video** (optional)
4. **MetaMask will GENERATE 12 words for you**
5. **Write them down securely** - this is YOUR new seed phrase
6. **Confirm by selecting the words in order**

**You don't need to enter anything - MetaMask creates it for you!**

---

### Scenario 2: Importing an EXISTING Wallet

If you already have a MetaMask wallet and want to use it:

1. **Click "Import Wallet"**
2. **Enter your existing 12-word recovery phrase**
   - Words must be in the correct order
   - Separate each word with a space
   - Check spelling carefully
3. **Set a password**
4. **Click "Import"**

**Only do this if you already have a wallet!**

---

### Scenario 3: Using Test Account (Easier for Development)

For local development, you don't need to use a seed phrase at all:

1. **Create a new wallet** (Scenario 1) or use existing
2. **After wallet is set up**, import a test account:
   - Click account icon (top right)
   - Click "Import Account"
   - Use private key from Hardhat (when you run `npx hardhat node`)
   - This gives you test ETH without needing seed phrase

---

## 📝 What Are the 12 Words?

The Secret Recovery Phrase is:
- **12 random words** (like: "apple", "banana", "chair", etc.)
- Generated by MetaMask when you create a wallet
- Used to recover your wallet if you lose access
- **Anyone with these words can access your wallet**

---

## ✅ Step-by-Step: Creating New Wallet

1. Open MetaMask extension
2. Click **"Get Started"**
3. Click **"Create a Wallet"** (NOT "Import Wallet")
4. Set password (8+ characters)
5. Watch security video (optional)
6. **MetaMask shows you 12 words** - write them down!
7. Click "Next"
8. **Confirm by selecting words in order**
9. Click "All Done"

**You're done! No need to enter anything - MetaMask created it.**

## 🆘 Common Questions

### "I don't have a seed phrase"
→ That's fine! Click "Create a Wallet" and MetaMask will generate one for you.

### "I lost my seed phrase"
→ If you're creating a new wallet for testing, just create a new one.
→ If you lost an existing wallet's phrase, you cannot recover it without the phrase.

### "Where do I enter the words?"
→ Only enter words if you're **importing** an existing wallet.
→ If **creating** a new wallet, MetaMask shows you the words - you just confirm them.

### "Can I skip this step?"
→ No, the seed phrase is required for wallet security.
→ But you can create a new wallet just for testing (it's free).
